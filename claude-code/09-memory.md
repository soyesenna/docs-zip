## 메모리 개요

Claude Code는 세션 간에 사용자의 선호도를 기억할 수 있습니다. 스타일 가이드라인, 일반적인 워크플로우 명령 등을 저장하여 매 세션마다 자동으로 컨텍스트에 로드됩니다.

---

## 메모리 계층 구조

Claude Code는 계층적 구조의 4가지 메모리 위치를 제공합니다.

| 메모리 유형 | 위치 | 목적 | 공유 대상 |
|------------|------|------|----------|
| **엔터프라이즈 정책** | macOS: `/Library/Application Support/ClaudeCode/CLAUDE.md`<br>Linux: `/etc/claude-code/CLAUDE.md`<br>Windows: `C:\ProgramData\ClaudeCode\CLAUDE.md` | IT/DevOps가 관리하는 조직 전체 지침 | 조직 내 모든 사용자 |
| **프로젝트 메모리** | `./CLAUDE.md` | 프로젝트의 팀 공유 지침 | 소스 컨트롤을 통한 팀원 |
| **사용자 메모리** | `~/.claude/CLAUDE.md` | 모든 프로젝트에 적용되는 개인 설정 | 본인만 (모든 프로젝트) |
| **프로젝트 메모리 로컬** | `./CLAUDE.local.md` | 프로젝트별 개인 설정 | 본인만 (현재 프로젝트) |

> **참고**: `./CLAUDE.local.md`은 **deprecated** 되었습니다. 대신 Import 기능을 사용하세요.

### 계층 로딩 순서

모든 메모리 파일은 Claude Code가 시작될 때 자동으로 컨텍스트에 로드됩니다. 계층 구조의 상위에 있는 파일이 먼저 로드되어 기반을 제공하며, 더 구체적인 메모리가 그 위에 덧붙여집니다.

```
1. 엔터프라이즈 정책     ← 조직 전체 (최우선 로드)
2. 사용자 메모리          ← 개인 설정
3. 프로젝트 메모리        ← 팀 공유
4. 프로젝트 메모리 로컬   ← 개인 프로젝트 설정 (deprecated)
```

### 각 메모리 유형별 활용 사례

**엔터프라이즈 정책**
- 회사 코딩 표준
- 보안 정책
- 컴플라이언스 요구사항

**프로젝트 메모리**
- 프로젝트 아키텍처
- 코딩 컨벤션
- 공통 워크플로우

**사용자 메모리**
- 코드 스타일링 선호도
- 개인 도구 단축키

**프로젝트 메모리 로컬 (deprecated)**
- 샌드박스 URL
- 테스트용 데이터

## CLAUDE.md Import 기능

CLAUDE.md 파일은 `@path/to/import` 구문을 사용하여 추가 파일을 가져올 수 있습니다.

### 기본 사용법

```markdown
# CLAUDE.md 예시

이 프로젝트는 다음 설정을 사용합니다:

@./docs/coding-standards.md
@./docs/architecture.md
@~/.claude/personal-preferences.md
```

### Import 규칙

| 규칙 | 설명 |
|------|------|
| **상대 경로** | CLAUDE.md 파일 위치를 기준으로 상대 경로 사용 가능 |
| **절대 경로** | `~/.claude/...` 와 같은 절대 경로 사용 가능 |
| **재귀 깊이** | 최대 5단계까지 재귀적 Import 가능 |
| **코드 블록 제외** | 마크다운 코드 스팬(`` ` ``)과 코드 블록 내의 Import는 평가되지 않음 |

### Import 활용 팁

사용자 홈 디렉토리의 파일을 Import하는 것은 팀원 각자가 개별 지침을 제공하는 편리한 방법입니다. 이전에는 `CLAUDE.local.md`가 비슷한 목적이었으나, Import 기능이 여러 git worktree에서 더 잘 동작하므로 이제 Import 사용이 권장됩니다.

## 메모리 탐색 방식

Claude Code는 메모리를 재귀적으로 읽습니다.

### 탐색 메커니즘

```
현재 작업 디렉토리(cwd)에서 시작
         ↓
상위 디렉토리로 이동 (루트 / 는 제외)
         ↓
발견한 모든 CLAUDE.md / CLAUDE.local.md 파일 읽기
```

### 예시

큰 리포지토리에서 `foo/bar/` 디렉토리에 있다면:

```
foo/bar/CLAUDE.md     ← 로드됨
foo/CLAUDE.md         ← 로드됨
CLAUDE.md             ← 로드됨 (루트는 제외)
```

### 하위 트리 발견

Claude는 현재 작업 디렉토리 아래의 하위 트리에 중첩된 CLAUDE.md 파일도 발견합니다. 단, 이 파일들은 시작 시 로드되지 않고 Claude가 해당 하위 트리의 파일을 읽을 때만 포함됩니다.

## 빠른 메모리 추가

`#` 단축키를 사용하면 메모리를 가장 빠르게 추가할 수 있습니다.

### 사용법

1. 입력창에 `#` 문자로 시작합니다.
2. 저장할 메모리 내용을 입력합니다.
3. 어떤 메모리 파일에 저장할지 선택하는 프롬프트가 나타납니다.

```
# 이 프로젝트는 2-space 들여쓰기를 사용합니다
```

이렇게 입력하면 저장할 메모리 파일을 선택하는 메뉴가 표시됩니다.

## /memory 명령어

세션 중 `/memory` 슬래시 명령어를 사용하여 시스템 에디터에서 메모리 파일을 열 수 있습니다.

### 기능

- 모든 메모리 파일을 시스템 에디터에서 열기
- 대규모 추가나 재구성에 적합
- 현재 로드된 메모리 파일 확인 가능

```
> /memory
```

명령어를 실행하면 편집할 메모리 파일을 선택할 수 있습니다.

---

## /init 명령어

코드베이스에 CLAUDE.md 파일을 부트스트랩합니다.

### 사용법

```bash
> /init
```

이 명령어는 프로젝트의 중요 정보, 컨벤션, 자주 사용하는 명령어를 저장하는 CLAUDE.md 파일을 생성합니다. Claude가 코드베이스를 분석하여 적절한 초기 내용을 자동으로 작성합니다.

## 조직 수준 메모리 관리

엔터프라이즈 조직은 모든 사용자에게 적용되는 중앙 관리 CLAUDE.md 파일을 배포할 수 있습니다.

### 설정 방법

**1단계**: 운영체제에 맞는 위치에 엔터프라이즈 메모리 파일 생성

| OS | 파일 위치 |
|----|----------|
| **macOS** | `/Library/Application Support/ClaudeCode/CLAUDE.md` |
| **Linux/WSL** | `/etc/claude-code/CLAUDE.md` |
| **Windows** | `C:\ProgramData\ClaudeCode\CLAUDE.md` |

**2단계**: 구성 관리 시스템을 통해 배포

| 배포 도구 | 설명 |
|----------|------|
| **MDM** (Mobile Device Management) | macOS/iOS 기기 관리 |
| **Group Policy** | Windows 도메인 환경 |
| **Ansible** | Linux/다중 플랫폼 환경 |

### 배포 예시 (Ansible)

```yaml
- name: Deploy enterprise CLAUDE.md
  ansible.builtin.copy:
    src: files/CLAUDE.md
    dest: /etc/claude-code/CLAUDE.md
    owner: root
    group: root
    mode: '0644'
```

## 모범 사례

### 구체적으로 작성

| 나쁜 예 | 좋은 예 |
|---------|---------|
| "코드를 적절히 포맷하세요" | "2-space 들여쓰기를 사용하세요" |
| "좋은 코드를 작성하세요" | "함수당 20줄 이내로 유지하세요" |
| "테스트를 작성하세요" | "모든 공개 함수에 단위 테스트를 작성하세요" |

### 구조화하여 정리

- 각 메모리를 불릿 포인트로 작성
- 관련 메모리를 설명이 포함된 마크다운 헤딩 아래에 그룹화

```markdown
# CLAUDE.md

## 코딩 컨벤션
- 2-space 들여쓰기 사용
- 세미콜론 사용 안 함
- 작은따옴표 사용

## 테스트
- 모든 테스트는 `__tests__/` 디렉토리에 배치
- Jest 사용
- 커버리지 80% 이상 유지

## 커밋 규칙
- Conventional Commits 형식 사용
- 한글로 커밋 메시지 작성
```

### 정기 검토

프로젝트가 발전함에 따라 메모리를 업데이트하여 Claude가 항상 최신 정보와 컨텍스트를 사용하도록 하세요.

## 요약

Claude Code의 메모리 시스템은 세션 간 일관성을 제공하는 핵심 기능입니다. 계층적 구조를 이해하고, Import 기능을 활용하며, 구체적이고 구조화된 메모리를 작성하는 것이 중요합니다. 정기적인 검토와 업데이트를 통해 항상 최신 상태를 유지하세요.
